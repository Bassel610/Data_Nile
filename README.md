# Data Nile

Full-stack React application with a Firebase + Express backend, QR code generation, and drag-and-drop file upload.

**Live demo:** https://data-nile.vercel.app

## Tech Stack

- **Frontend:** React 18, Material-UI, React Router, SweetAlert2
- **Backend:** Node.js, Express, Firebase
- **Other:** qrcode.react, react-dropzone, react-icons, FontAwesome

## Project Structure

```
Data_Nile/
├── my-app/         # React frontend
├── My-Backend/     # Express server
└── data nile-plan/ # Project planning notes
```

## Getting Started

```bash
# Frontend
cd my-app
npm install
npm start

# Backend
cd My-Backend
npm install
npm start
```
